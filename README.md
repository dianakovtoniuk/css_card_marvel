# Captain Marvel Card Effect

A small CSS-only hover animation built with transitions and transforms. No JavaScript.

## How it works

On hover, the character image grows and slides to the right while the text block fades in from the left. The card itself uses a diagonal red-to-purple gradient.

## Structure

```
creative captain marvel card effect/
├── index.htm
├── style.css
└── 1.png
```

## Usage

Clone the repo and open `index.htm` in a browser. No build step or dependencies are needed.

## Customization

- Replace `1.png` with any transparent PNG
- Edit the gradient colors in the `.card` rule
- Change the title and text in `index.htm`
- Tweak the transition speed (`0.5s`) in the `img` and `.content` rules
